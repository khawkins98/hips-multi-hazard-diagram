# HIPS Single-Hazard Causal Diagram

Visualizes "what causes this hazard" and "what it causes" for a single [UNDRR Hazard Information Profiles (HIPs)](https://www.preventionweb.net/drr-glossary/hips) hazard, grouped by hazard type. Designed for embedding via iframe.

## Development

```bash
npm install
npm run dev
```

## Usage

Select a hazard via query parameter:

```
?hip=TL0305
```
